# Evidence Pack Index

This folder contains the technical documentation pack for the PixelCatsFork solution.

## Documents

- Technical Project Report explains the project purpose, the engineering problem being solved, the implementation approach, and the main technical achievements and limitations.
- System Architecture describes the high-level system architecture, the responsibilities of each project, and the main data flows between the console apps, the shared display layer, and the external leaderboard service.
- Software Design documents the internal design of the main modules, the validation logic, configuration handling, error handling, and maintainability and security considerations.
- API Documentation captures the discovered HTTP endpoints consumed by the codebase and records the observed request and response structures.
- Database Design explains the storage model used in the repository and why no internal database schema is present.
- Modelling and Diagrams provides Mermaid diagrams for context, containers, workflow, activity flow, and the discovered storage model.
- Programming Languages inventories the languages, frameworks, libraries, build tools, testing tools, and deployment assumptions visible in the repository.
